# 家长沟通话术库

> 知识层 ｜ 语言：zh 主源 ｜ 类型：话术工具
> 遵循 DESIGN.md §1.3：不评判家长养育方式，不制造育儿焦虑；§8：可落地、中立科学。
> 用法：话术是「可以先试试」的起点，不是标准答案；按孩子的气质与当下情境调整。

## 五步沟通框架

> 综合来源：《如何说孩子才会听》《去情绪化管教》《全脑教养法》《非暴力沟通》《正面管教》

### 第 1 步：接住情绪（先连接，后处理）

> 来源：《去情绪化管教》《全脑教养法》——情绪风暴中，理性脑暂时「下线」，讲道理基本无效；先帮情绪命名、让身体平静。

- ❌「这有什么好哭的！」
  ✅「你现在很难过，塔倒了让你很生气。」（命名情绪，《全脑教养法》）
- ❌「不许发脾气！再闹就不管你了。」
  ✅「我看到你很生气。我在这儿，等你准备好我们再说话。」（陪伴式连接，《去情绪化管教》）
- ❌「你怎么又来了，烦不烦。」
  ✅「你的感受很大，大到装不下了，我们一起深呼吸三次试试。」（平静身体，《去情绪化管教》）

### 第 2 步：描述事实（不贴标签、不翻旧账）

> 来源：《如何说孩子才会听》《非暴力沟通》——描述所见的事实，把「改正」的主动权留给孩子。

- ❌「你怎么总是把水洒得到处都是！」
  ✅「我看到桌上有洒出来的水。」（描述代替指责，《如何说孩子才会听》）
- ❌「你就是个丢三落四的孩子。」
  ✅「书包放在门口，水杯还在茶几上。」（观察代替评判，《非暴力沟通》）
- ❌「跟你说过一百遍了！」
  ✅「鞋。」（一个词代替唠叨，《如何说孩子才会听》）

### 第 3 步：有限选择（两个都可接受，让孩子有掌控感）

> 来源：《正面管教》——选择的本质是「你来决定小事」，减少权力对抗。

- ❌「快穿衣服，别磨蹭！」
  ✅「红色这件还是蓝色这件，你来选？」
- ❌「马上去洗澡！现在！」
  ✅「你想现在去洗澡，还是拼完这块拼图 5 分钟后去？」
- ❌「把电视关了，没商量。」
  ✅「这一集结束后是你自己关，还是和我一起关？」（配合「预告」使用，见场景话术）

### 第 4 步：共同解决（把问题还给孩子）

> 来源：《P.E.T.父母效能训练》《如何说孩子才会听》——孩子参与制定的方案，执行阻力更小。

- ❌「以后不许再抢妹妹的东西，听到没有！」
  ✅「两个人都想玩这个小汽车。我们来想想办法，你能说出一个主意吗？」（没有输家协商，《P.E.T.》）
- ❌「我不管你用什么办法，明天开始不许迟到。」
  ✅「早上总是来不及。我们列一列原因，再一起挑一个办法明天试试？」（问题解决五步，《如何说孩子才会听》）
- ❌「说了不行就是不行。」
  ✅「我不同意现在买（界限）。我们可以拍下来记到生日愿望清单里（出口）。」（界限 + 出口，《Good Inside》）

### 第 5 步：描述式表扬（夸过程和具体行为，不夸聪明）

> 来源：《如何说孩子才会听》《正面管教》——描述式表扬让孩子知道「哪里做对了」，可复制、可积累。

- ❌「你真聪明！」
  ✅「你刚才把积木倒了三次都没有放弃，第四次自己搭起来了。」（描述努力）
- ❌「真是妈妈的好孩子！」
  ✅「你看到妹妹哭了，把玩具递给了她，她就不哭了。」（描述行为 + 影响）
- ❌「太棒了！画得真好！」
  ✅「你用了三种颜色画天空，能给我讲讲这张画吗？」（描述细节 + 邀请表达）

## 高频场景话术

> 每条标注方法来源书。同一场景先试一条，观察孩子的反应再调整。

### 场景 1：起床气

- 「早上的你好凶呀。来，靠在我身上醒一醒。」（接住情绪，《去情绪化管教》）
- 「你想先穿外套还是先刷牙？」（有限选择，《正面管教》）
- 「我们把叫醒方式换个游戏：今天你是被『袜子怪』吓醒，还是被挠痒痒笑醒？」（游戏化解，《游戏力》）
- 「我把早餐的香味『运』过来了，闻一闻，是什么？」（感官唤醒，《游戏力》）

### 场景 2：拒绝关电视

- （提前预告）「还有 5 分钟。这一集结束后是你自己关，还是和我一起关？」（预告 + 有限选择，《正面管教》）
- 「我知道这一集特别好看，关掉让你舍不得。」（接住情绪，《全脑教养法》）
- 「你舍不得关电视（感受），同时我们约好的是看一集（界限）。我们把它加到『明天先看』清单上。」（感受 + 界限 + 出口，《Good Inside》）
- 「电视旁的便条说什么来着？」（指向事先贴好的约定便条，《如何说孩子才会听》）

### 场景 3：打人 / 咬人

- 「我不会让你打人（界限）。你可以生气，我陪着你。」（界限 + 陪伴，《Good Inside》）
- （平静后）「刚才发生了什么？你当时是什么感觉？下次可以怎么做？」（反思三问，《去情绪化管教》）
- 「你气到想打人的时候，可以打这个枕头，或者来找我抱紧。」（可接受的情绪出口，《去情绪化管教》）
- 「小明的胳膊被打了，很疼也很难过。你想做点什么让他好受一些？」（引导修复，《去情绪化管教》）
- 「你好像特别想玩那个玩具。用嘴巴说：『可以给我玩一下吗？』我们练一遍。」（补技能：教替代表达，《如何说孩子才会听》）

### 场景 4：公共场合哭闹（超市 / 商场）

- 蹲下、放低声音：「你很想要那个东西，拿不到让你特别难受。我在这儿陪着你。」（先连接、缩小声场，《去情绪化管教》）
- 「我不会买这个（界限）。我们可以拍下来，记到愿望清单里（出口）。」（界限 + 出口，《Good Inside》）
- （出门前预演）「今天去超市，如果看到很想吃的糖，我们拍下来记在清单上，今天不买。你跟我讲一遍这个计划。」（脚本化预告，《Good Inside》）
- 「我们需要离开这里。你想自己走，还是牵着我走？」（有限选择保住体面，《正面管教》）

### 场景 5：不肯吃饭

- 「晚饭时间到 7 点。7 点收桌，之间你来决定吃多少。」（界限内交还控制权，《正面管教》）
- 「这顿不合口味没关系，碗里有没有哪一样你愿意先吃一口的？」（降低门槛 + 有限选择，《正面管教》）
- 「西兰花像小树，你是恐龙，要先吃树顶还是树干？」（游戏化，《游戏力》）
- 不追喂、不 coerce：「你好像不饿。那先去玩，下一顿再见。」（自然结果，平静执行，《正面管教》）
- （饭后复盘，不对饭桌现场）「今天晚饭哪里不合胃口？明天想加点什么？」（复盘式倾听，《P.E.T.父母效能训练》）

### 场景 6：分离焦虑（送园 / 出门）

- 「你会想我，我也会想你。这是我的『爱的口袋』（亲一下手心），想我的时候握一握。」（仪式化连接，《游戏力》）
- 「抱一下、亲一下、挥挥手——然后妈妈就走。老师说你想我的时候可以看看小书包上的挂件。」（确定的可预期告别流程，简短不拖延）
- 「分开 3 次拥抱，晚饭后又见面了。看，这是时钟上的那个时间。」（时间可视化 + 重聚预告，《忍住！别插手》）
- 「舍不得妈妈走，说明你很爱我。老师会照顾你，妈妈下午 4 点准时来。」（命名感受 + 确定性承诺，《全脑教养法》）

### 场景 7：抢玩具（自家或伙伴间）

- 「两个人都想玩。我们想想办法：轮流？交换？还是一起玩？你选哪种？」（共同解决，《P.E.T.父母效能训练》）
- 「沙漏立起来，漏完就交换。」（工具代替人裁决，《忍住！别插手》）
- 「我知道你还没玩够，被拿走让你很急。可以跟他说：『我还没玩够，再给我 3 分钟。』」（教句子，《如何说孩子才会听》）
- 「玩具是小明的，他要带回去了。你可以问他：『明天还能借我玩吗？』」（归属确认 + 请求句式，《如何说孩子才会听》）

### 场景 8：孩子说「我讨厌你！」

- 「你现在是气坏了（翻译：感受太大，不是真话）。我在这儿。」（行为是信号，《Good Inside》）
- 「你讨厌的是我不让你继续玩，不是我这个人。」（帮孩子区分人和事，《全脑教养法》）
- （不接招、不受伤宣言）「即使你讨厌我，我也爱你。等我们都平静了再聊。」（界限内稳，《Good Inside》）
- （复盘时）「你说讨厌我的时候，到底想要什么？想再玩一会儿，还是想要我陪你？」（寻找需要，《非暴力沟通》）

### 场景 9：害怕黑暗 / 不敢睡

- 「黑黑的房间里你觉得有可怕的东西。来，我们开着小夜灯，你说说那个东西长什么样，把它画出来。」（外化恐惧，《全脑教养法》）
- 「给它起个名字，跟它说：『你不许吓我，我妈妈就在隔壁。』」（赋能句式，《游戏力》）
- 「白天我们玩『手电筒寻宝』，晚上你就是拿着手电筒的探险家。」（反转角色，《游戏力》）
- 「你害怕的时候可以随时叫我。睡前我们做『呼吸 5 次 + 抱 10 秒』，每天一样。」（固定程序 = 安全感，《去情绪化管教》）

### 场景 10：磨蹭不出门

- 「出门清单上还差哪两项？」（指向流程图，代替催促，《忍住！别插手》）
- 「计时器设 5 分钟，铃响前穿好鞋的就是冠军。预备——开始！」（计时器 + 游戏化，《1-2-3 Magic》《游戏力》）
- 「你想自己走到车那边，还是让我把你『运』过去——飞机式还是袋鼠式？」（游戏化收尾，《游戏力》）
- （反复无效时）「我数到 3 我们就出门，你自己走还是我牵着你走？」（数数 + 有限选择，《1-2-3 Magic》《正面管教》）
- （事后复盘，不对现场）「今天早上迟到了。我们把早晨的事重新排一排，怎么排能快一点？」（共同解决，《P.E.T.父母效能训练》）

## 表达白名单（推荐用语习惯）

> 目标：给沟通留出不确定性与协商空间，减少评判与定性。

| 推荐用语 | 作用 | 来源 |
|----------|------|------|
| 「更可能是……」 | 用推测代替断言，例如「他更可能是累了，不是故意捣乱」 | 《Good Inside》（行为信号视角） |
| 「可以先试试……」 | 降低方法压力，允许调整 | 《去情绪化管教》 |
| 「你在表达某种需要」 | 把行为翻译成需求，对自己和孩子都适用 | 《非暴力沟通》 |
| 「我注意到……」 | 观察开场，代替评判开场 | 《非暴力沟通》 |
| 「……同时……」 | 和善与坚定并存的句式：「我爱你，同时今天不买」 | 《正面管教》 |
| 「你需要我做什么？」 | 顾问式支持，交还主动权 | 《自驱型成长》 |
| 「说说看」 | 门把手式倾听，打开话匣子 | 《P.E.T.父母效能训练》 |

## 表达黑名单（禁用语句 + 替代说法）

> 目标：移除条件化的爱与比较、定性式指责、情绪压抑类语言。已说过也没关系，可以用「修复对话」重讲一遍（见《Good Inside》修复话术）。

| 禁用 | 原因 | 替代说法 |
|------|------|----------|
| 「你再这样，妈妈不喜欢你了」 | 把爱变成行为筹码，制造条件化安全感 | 「我爱你，同时这件事不行。我们可以生气，也可以想办法。」（《正面管教》） |
| 「别人家孩子都会」 | 横向比较制造羞耻，不提供任何方法 | 「你上个月还不会系鞋带，现在会了。这个也先从一步开始练。」（和自己的过去比，《自驱型成长》） |
| 「你就是故意的」 | 定性为动机邪恶，堵死沟通 | 「我想知道刚才发生了什么。」（探询代替定罪，《去情绪化管教》） |
| 「男子汉不许哭」 | 压抑情绪表达，情绪不会消失只会变形 | 「哭出来没关系，哭完我们再想办法。」（接住情绪，《全脑教养法》） |
| 「你怎么这么笨 / 这么胆小」 | 人格标签，会内化为自我认知 | 「这个对你还太难了，我们把它拆小一点。」（对事不对人，《正面管教》） |
| 「我数到 3！……」（附威胁咆哮） | 高压威慑，孩子只学会了害怕 | 数数法本身可用，但前提是平静语气 + 预先约定的后果（《1-2-3 Magic》），而非临时咆哮 |
| 「随便你，我不管了」 | 撤回式冷暴力 | 「我现在很生气，需要 2 分钟冷静，然后我们接着谈。」（家长自用暂停，《去情绪化管教》） |

## 表扬与批评

### 描述式表扬 vs 空洞夸奖

> 来源：《如何说孩子才会听》《正面管教》。公式：**描述所见 + 描述感受/影响**，必要时加一个词总结。

| 空洞夸奖 ❌ | 描述式表扬 ✅ |
|------------|----------------|
| 「你真聪明！」 | 「这道题你换了一种方法算出来了。」 |
| 「好棒啊！」 | 「你把画收进了抽屉，桌面变整齐了，找东西也快了。」 |
| 「真是乖孩子！」 | 「你等我打完电话才说话，等我的时候你画了这张画。」 |
| 「完美！天才！」 | 「你练了三遍就能自己扣扣子了——这就叫『练出来了』。」（加一个词收尾） |

要点：
- 夸**努力、策略、进步**，不夸天赋（聪明、天才）——天赋夸多了，孩子反而回避挑战（《自驱型成长》压力视角）。
- 表扬**具体的行为**与**对他人/环境的影响**，孩子才知道哪里做对了、可以复制（《如何说孩子才会听》）。

### 批评：对事不对人

> 来源：《去情绪化管教》《非暴力沟通》。公式：**描述行为 + 说明影响/感受 + 指向修复或下一步**。

- ❌「你真是个自私的孩子！」
  ✅「妹妹的画被撕了（行为），她哭得很伤心（影响）。我们一起想想怎么让她好受一点（修复）。」
- ❌「你怎么老是把水杯弄倒！」
  ✅「水洒在桌上了（行为），本子湿了（影响）。抹布在洗手池边，你来擦还是我们一起擦（下一步）？」
- ❌「撒谎！你就是个骗子！」
  ✅「你说是 8 点睡的，手表显示 9 点（观察）。我想知道你为什么这么说（探询）——是怕我生气吗？我们可以重新说一遍。」
- 时机：情绪风暴中不批评，平静后再谈；一次只谈一件事，不翻旧账（《去情绪化管教》）。
- 家长失言后的修复模板：「刚才我吼了你 / 说了伤人的话，那不是你的错，是我没管好自己的情绪。我想抱抱你，重新开始。」（《Good Inside》）
