# kid-learning

> 分龄启蒙计划引擎。**内容必须匹配发展里程碑，难度跟着孩子的真实反馈走。**

## ⚠ 执行硬约束

1. **分龄强制**：内容难度对照 `milestones.json` 当前月龄段；不出现超龄或明显低幼内容
2. **屏幕时间红线**：不推荐累计屏幕时间 >30 分钟的内容；18 月龄以下不推荐任何屏幕内容（视频通话除外）——对照 `safety-rules.json → screen_time`
3. **双版本输出**：默认同时输出基础版（15-30 分钟）与进阶版（30-60 分钟），家长按当日时间选择；明确指定版本时只输出该版
4. **难度动态调整强制执行**：读取近 7 天日志学习反馈——连续 ≥3 天接受度低 → 必须降档；连续 ≥3 天全部完成且接受度高 → 必须升档（在输出中说明调整依据）
5. **可落地**：每个环节含操作方法 + 互动提问设计（至少 2 个具体问题）+ 观察要点；绘本优先从 `knowledge/picture-books.md` 书单中选取并附共读要点，书单无合适项时用「主题+类型」描述（如「颜色认知纸板书」），**不得凭空捏造书名**
6. **不布置打卡任务**：完成记录是勾选框不是指标；护理模式时长减半且只保留温和内容（绘本共读/音乐律动）

## 1. 何时调用

- 「今日学习计划」「今天的启蒙安排」→ 生成
- kid-plan 聚合时被调用（学习计划节）

## 2. 输入

| 参数 | 必填 | 默认 | 说明 |
|------|------|------|------|
| `date` | 否 | 今天 | — |
| `level` | 否 | 双版本 | basic / advanced / both |
| `child_id` | 否 | active_child | — |

## 3. 工作流

### 步骤 1 · 上下文加载

1. 档案：发展状态（motor/language/cognitive_level）、`habits_target[]`（习惯培养选题）、`interests[]`（兴趣联动）、`parent_time_daily_min`（时长上限）
2. 规则库：education / routine 类 active 条目
3. 里程碑：`milestones.json` 当前月龄段四域 items（选题锚点）+ 下一阶段重点
4. 行为数据：近 7 天日志学习记录（接受度/完成情况）+ `tags.md` 能力观察（强项/短板）

### 步骤 2 · 难度判定（硬约束 4）

```
近7天日志学习环节：
  接受度=低 连续≥3天        → level_shift = -1（降档）
  完成率100% 且接受度=高 连续≥3天 → level_shift = +1（升档）
  数据不足（<3天记录）        → 维持当前档，输出注明「数据不足」
```

档位基于里程碑：当前月龄段 = 标准档；-1 = 上一阶段；+1 = 下一阶段（进阶版在此基础上再进半步）。

### 步骤 3 · 六维度选题

| 维度 | 选题逻辑 |
|------|---------|
| 绘本阅读（核心环节） | 从 `knowledge/picture-books.md`（按 vault 语言取 knowledge/ 或 knowledge/en/）月龄段书单中选题：月龄适配 + 兴趣联动（喜欢工程车 → 车主题绘本）+ 短板补强（语言滞后 → 高重复句式绘本）；输出须含该书的「共读要点」 |
| 语言启蒙 | 对照 language 里程碑缺口（词汇量/短语/表达） |
| 数学认知 | 2y 前感知（大小/多少），2-4y 数感（点数/配对），4y+ 操作（分类/规律），6y+ 抽象（凑十/图形） |
| 艺术启蒙 | 大感官涂鸦（1-2y）→ 命名涂鸦（2-4y）→ 有主题创作（4y+）；材料家用可洗 |
| 常识科普 | 生活场景延伸（做饭=食物来源，出行=交通规则） |
| 习惯培养 | 从 `habits_target[]` 轮换（每次 1 个），结合年龄段习惯养成要点 |

每日组合：核心 1-2 个 + 拓展 1-2 个 + 习惯培养 1 个（对齐模板三节结构）。

### 步骤 4 · 组装输出（模板：learning-plan.md）

```
总时长 / 难度等级（+ 调整依据说明）
▌核心环节：绘本共读（阅读目标 / 共读要点 / 互动提问 ≥2 个）
▌拓展启蒙：（核心内容 / 操作方法 / 观察要点）
▌习惯培养：今日习惯 + 家长话术建议
完成记录：□ 全部完成 □ 部分完成 □ 未完成
```

进阶版在基础版上增加拓展环节与提问深度，不简单加倍时长。

### 步骤 5 · 护理模式

`health_status=ill/recovering`：总时长减半、剔除需专注久坐环节、保留绘本共读与音乐律动、标注「康复期安排」。

## 4. 输出契约

| 项 | 值 |
|----|----|
| 路径 | `02_plans/<child-id>/YYYY-MM-DD.md` 学习计划节（frontmatter 由首次写入方维护） |
| 双版本 | 默认 both；护理模式强制基础版 |
| 调整依据 | level_shift ≠ 0 时必须在输出中说明（引用日志日期） |

## 5. 边界

- 不做「智力测评/天赋判断」类输出；里程碑差距只建议温和练习 + 儿保评估提示
- 不推荐需要付费课程/APP 才能完成的内容（材料家用可替代）
- 绘本不捏造具体书名与作者（除非广为人知的经典），用主题+类型描述

## 6. 降级路径

| 场景 | 行为 |
|------|------|
| 档案发展维度全空 | 用月龄对应里程碑默认档 + 说明；引导 kid-profile 补充 |
| 无日志数据 | 难度维持标准档，输出注明「无反馈数据，建议连续记录 3 天后优化」 |
| 家长时间 <15 分钟 | 只输出核心环节微缩版（单一绘本共读 10 分钟） |

## 7. 幂等保证

同日重新生成完整替换学习计划节；难度判定只依赖日志事实（幂等）。

## 8. 自检清单

- [ ] 难度对照了正确月龄段里程碑；level_shift 判定有日志依据（**引用了具体日志日期与反馈内容**，如「基于 09-07 颜色配对 2/3 正确」）
- [ ] 屏幕时间红线零违反
- [ ] 核心环节含 ≥2 个互动提问；观察要点齐备
- [ ] 习惯培养取自 habits_target（或说明轮换逻辑）
- [ ] 双版本（或指定单版）+ 时长符合 parent_time 上限
- [ ] 护理模式正确应用（如适用）
- [ ] 绘本选自 picture-books.md 书单（或主题+类型描述），共读要点已附；无捏造书名、无付费内容依赖
