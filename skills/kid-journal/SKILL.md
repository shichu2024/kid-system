# kid-journal

> 闭环的起点：日志驱动标签沉淀 → 标签驱动方案优化。**不编造家长未提及的维度。**

## ⚠ 执行硬约束

1. **前置守门**：vault 未初始化 → 引导 kid-init；档案不存在 → 引导先建档
2. **不编造**：口述中未提及的维度，日志中标注「未记录」，禁止臆测填充
3. **异常识别强制**：口述中出现 发烧/腹泻/呕吐/咳嗽/出疹/受伤 等健康异常关键词时，必须置 `health_status: ill`（或 recovering）并触发护理模式提示——**不得静默记录**
4. **就医红线**：命中 `references/safety-rules.json` 的 `emergency_red_lines`（如 <3 月龄发热≥38°C、精神萎靡、抽搐、脱水征）→ **报告开头**显著提示立即就医，并附免责声明
5. **标签沉淀带证据**：每个写入 tags.md 的标签必须附出现次数/接受度/日期证据；单次出现的观察不直接定性，标注「观察中」
6. **单日幂等**：同日期日志已存在 → 询问「追加/覆盖」，默认追加新信息并保留原有记录
7. **frontmatter 合规**：符合 `references/journal-schema.json` journal 定义（required: date, child_id, health_status）

## 1. 何时调用

- 「记录今天」「写日志」+ 口述当日情况（任意维度组合）
- 「记录饮食/运动/学习」单维度补录
- 「查看昨天的日志」「上周日志」「搜索 吃了胡萝卜 的记录」→ 查询
- 家长在闲聊中自然描述了孩子当日表现且当日无日志 → 可主动提议记录

## 2. 输入

| 参数 | 必填 | 默认 | 说明 |
|------|------|------|------|
| 口述内容 | 是 | — | 自然语言日记/片段（查询类指令除外） |
| `date` | 否 | 今天 | 支持补录昨日及更早（ISO 日期） |
| `child_id` | 否 | active_child | 多孩切换 |

## 3. 工作流

### 步骤 1 · 上下文加载

1. 定位儿童档案（birthdate → 重算当日月龄）
2. 读近 7 天日志 + `tags.md`（用于对比判断「新出现」还是「重复出现」）
3. 读 `references/safety-rules.json` 红线（异常识别用）

### 步骤 2 · 五维度解析

把口述内容映射到日志模板（`99_system/templates/<lang>/journal.md`）：

| 维度 | 解析目标 | 量化字段 |
|------|---------|---------|
| 饮食 | 每餐食物、食量、接受度 | 偏少/正常/偏多；喜欢/一般/拒绝 |
| 运动 | 类型、时长、强度、场地、兴趣反馈 | 分钟数 |
| 学习 | 内容、时长、接受度、掌握情况、难点 | 高/中/低 |
| 睡眠 | 夜间时长/质量、午睡时长 | 小时/分钟；好/一般/差 |
| 情绪与健康 | 整体情绪、特殊情况、异常行为 | happy/calm/fussy/crying；healthy/ill/recovering |

含糊表述的处理：「吃得不错」→ 食量=正常、接受度=一般（不夸大）；「睡得还行」→ 质量=一般。
解析后**回显结构化结果**让家长快速确认/修正，再写盘。

### 步骤 3 · 异常识别与护理模式

1. 关键词/语义命中健康异常 → `health_status: ill` + `illness_notes`
2. 对照 `emergency_red_lines`：命中 → 报告开头红色就医提示（条件 + 建议动作），本技能不展开医疗建议
3. 未命中红线但生病 → 输出通用护理提示（休息/补水/清淡饮食）+ 「下次生成方案将自动切换护理模式（清淡饮食、暂停剧烈运动）」说明；家长同步描述行为困扰（闹情绪/抗拒吃饭等）时，可引用 `knowledge/problem-navigation.md` 对应条目给 L1 即时应对（标注来源章节）
4. 恢复期口述（「好多了」）→ `health_status: recovering`

### 步骤 4 · 标签沉淀（更新 tags.md）

对每个维度提取候选标签，按机械规则沉淀：

| 信号 | 规则 | 动作 |
|------|------|------|
| 食物接受度 | 单日喜欢/拒绝 | 计入计数（「近30天出现N次」），N≥3 才升级为稳定标签；否则「观察中」 |
| 能力表现 | 首次出现新技能（如「会垒10块积木」） | 写入 能力观察·强项/短板 + 证据日期 |
| 兴趣点 | 主动选择/反复提及某类活动 | 计入「游戏选择倾向 N/M 次」 |
| 异常模式 | 同一异常连续 ≥2 天 | 标注「持续观察」，提示 kid-review 预警阈值（3 天） |

写入格式（tags.md 三节内追加/更新，不删除既有条目，除非被新证据推翻）：

```markdown
- **喜欢** 西兰花（近30天出现8次，接受度 高）`updated: 2026-09-08`
```

### 步骤 5 · 输出简报

1. 日志确认摘要（五维度一览）
2. 标签沉淀明细（新增/更新/观察中）
3. 健康状态说明（含就医提示，如命中）
4. 下一步建议：「今日方案」生成次日方案（自动适配护理模式）

## 4. 查询类工作流（view/search）

- 按日期/日期段读取 `01_journal/`：分维度摘要展示
- 关键词搜索：遍历日志正文，返回命中行 + 日期 + 高亮上下文
- 结果附简单统计（如「本周共记录 5 天，外出运动 3 次」）

## 5. 输出契约

| 项 | 值 |
|----|----|
| 日志路径 | `01_journal/<child-id>/YYYY-MM/YYYY-MM-DD.md` |
| frontmatter | date / child_id / health_status / illness_notes? / mood_summary? / tags[] |
| 标签更新 | `00_profiles/<child-id>/tags.md` 三节（饮食偏好/能力观察/兴趣点），每条带证据与 updated 日期 |
| 模板 | `99_system/templates/<lang>/journal.md` |

## 6. 边界

- 不做医疗诊断与用药建议（红线提示 + 通用护理建议为上限）
- 不评价家长（「你今天陪太少了」❌ → 只记录事实）
- tags.md 只增不删（除非新证据推翻，需在条目注明修订原因）
- 补录历史日志不触发「次日方案」提示（日期已过）

## 7. 降级路径

| 场景 | 行为 |
|------|------|
| 口述过于简短（只有一句话） | 补充询问 1 轮（「今天吃饭睡觉情况怎么样？」），仍简短则如实记录、其余「未记录」 |
| 家长拒绝回显确认 | 按解析结果直接写盘，简报中注明「未经确认」 |
| 日期未来 | 拒绝，说明只能记录今天及过去 |
| tags.md 缺失 | 按 kid-init 骨架格式重建（三节空结构）再沉淀 |

## 8. 幂等保证

- 同日重复记录 → 追加模式（保留原记录，新增内容合并到对应维度）
- 相同标签重复沉淀 → 只更新计数与日期，不产生重复条目

## 9. 自检清单

- [ ] 日志五维度：未提及的维度标注「未记录」而非编造
- [ ] health_status 正确（异常未被静默）
- [ ] 命中就医红线时提示位于报告开头
- [ ] 标签沉淀：每个新标签有证据（次数/日期），单次观察标注「观察中」
- [ ] tags.md 更新未删除既有条目
- [ ] frontmatter 符合 journal-schema
- [ ] 输出了沉淀摘要 + 下一步建议
