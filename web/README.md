# kid-system Web 仪表盘

单文件零构建的只读可视化仪表盘（`dashboard.html`），读取你的本地 vault 数据展示：孩子状态、每日方案、成长日志、育儿规则、周期复盘与里程碑时间轴。

## 使用方式

仪表盘通过 `fetch` 读取 vault 文件，浏览器直接双击打开（`file://` 协议）会被 CORS 拦截，需要用本地 HTTP 服务：

```bash
# 方式 1：Python（推荐，系统自带）
cd <你的 vault 目录>
python -m http.server 8080

# 方式 2：Node
npx serve <你的 vault 目录> -p 8080

# 方式 3：在仓库根目录起服务（可同时访问示例数据）
cd /path/to/kid-system
python -m http.server 8080
```

然后浏览器打开 `http://localhost:8080/web/dashboard.html`：

- **示例数据**：点击右上角「示例数据」按钮，自动加载 `examples/demo-vault/`（糖糖 · 24 月龄 · 鸡蛋过敏 · 完整一周）
- **你的数据**：在地址栏填入 vault 相对路径或 `http://localhost:8080`（如果你把 vault 目录单独起了服务），点「加载」

## 页面说明

| 页面 | 内容 |
|------|------|
| 成长总览 | 孩子状态卡（月龄/过敏高亮）、最新方案、最近复盘、近 7 天日志、健康提醒、动态标签 |
| 儿童档案 | profile.md 原文 + tags.md 动态标签 |
| 成长日志 | 时间线倒序，健康状态/情绪/标签徽章，可展开全文 |
| 每日方案 | 按日期倒序，护理模式高亮，可展开全文 |
| 育儿规则 | 规则库原文 + 冲突处理记录 |
| 成长复盘 | 周/月复盘报告 + 里程碑时间轴 |

## 边界

仪表盘是**只读**视图。编辑档案、写日志、生成方案、注入规则请回到 Claude Code 使用技能指令（「查看孩子档案」「记录今天」「今日方案」「注入规则」等），修改后刷新本页即可看到最新数据。

> 免责声明：页面展示的育儿建议仅供参考，不能替代专业医疗诊断与治疗。
